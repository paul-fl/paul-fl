# Paul Florescu

Physicist working on radiation detectors, simulation and machine learning for physics data.

- **Now:** PhD researcher at the Surrey Space Centre (from Oct 2026): compact Cherenkov detectors for space radiation (SiPMs, Geant4/GRAS simulation, a balloon-flight prototype).
- **Before:** MSci Physics, Imperial College London (2026). Master's project: CNN classifier for a dark-sector search in MicroBooNE LArTPC data. Detector work on COMET at KEK (scintillators, DAQ, Geant4). UROP on the MAGIC CubeSat magnetometer.

**Tools:** Python (NumPy, pandas, PyTorch), C++/Geant4, ROOT, GRAS, Jupyter, Git, Linux, PIC assembly.

## Selected projects
- [MicroBooNE_DarkTrident_CNN](https://github.com/paul-fl/MicroBooNE_DarkTrident_CNN): CNN training and inference for dark trident vs background in LArTPC images.
- [LYSOSimulation](https://github.com/paul-fl/LYSOSimulation): Geant4 simulation of a LYSO scintillator crystal with optical physics.
- [Y3ComputationalProject](https://github.com/paul-fl/Y3ComputationalProject): numerical methods for a Higgs discovery significance analysis.
- [MicroprocessorsProject](https://github.com/paul-fl/MicroprocessorsProject): PIC assembly firmware (ADC, keypad, LCD, UART, timer) for a frequency spectrum project.
